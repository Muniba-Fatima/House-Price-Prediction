# House-Price-Prediction
## Conclusion

In this project, a House Price and Category Prediction system was developed using machine learning. The main objective was to predict numerical house prices and classify houses into three categories: Low, Medium, and High value.

Two machine learning models were implemented: Linear Regression and Random Forest Classifier. Linear Regression was used to predict house prices, while Random Forest was used to classify houses into the three value categories. Data preprocessing was performed to handle missing values and remove extreme price outliers. Visualizations were also created to understand the dataset and analyze the model results.

The Linear Regression model achieved an **R² score of 0.752**, indicating that it explained approximately 75.2% of the variation in house prices in the test dataset. Its Mean Absolute Error (MAE) was **2.231**, meaning that the average absolute prediction error was 2.231 units of the target variable. The Random Forest Classifier achieved an accuracy of **76.6%**, showing that it correctly classified approximately 76.6% of the test samples into the appropriate house value categories.

Overall, the results demonstrate that both models can be used for different housing prediction tasks. Linear Regression provided numerical price predictions, while Random Forest performed category classification. This project provided practical experience in data preprocessing, visualization, regression, classification, and model evaluation. In the future, performance could be improved by using additional housing features, testing other machine learning algorithms, and tuning model parameters.
